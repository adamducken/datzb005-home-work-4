# DatZB005 — 4. mājasdarbs

`atzimes.bat` ar `FOR` ciklu apstrādā astoņas atzīmes: izvada katru atzīmi,
aprēķina skaitu, summu, mazāko, lielāko, vidējo un sekmīgo/nesekmīgo skaitu.
Sekmīga atzīme ir vismaz 4. Vidējā atzīme tiek parādīta ar divām zīmēm aiz
komata, atmetot atlikušās zīmes. Sarakstu var mainīt `FOR` rindā; tajā jābūt
vismaz vienai atzīmei, un visām jābūt veseliem skaitļiem no 1 līdz 10.

Palaist Windows Command Prompt:

```bat
atzimes.bat
```

Cikla ķermenī ir piecas izpildāmas rindas un komentāri latviešu valodā.
GitHub Actions pārbauda visu izvadi ar īstu Windows `cmd` uz `windows-latest`.
Izmantots tāds pats Windows runner un checkout kā `sub_9_1` un `sub_9_2`.

Atgādne un iesniedzamais Word/PDF dokuments tiks veidots vēlāk.
Uzdevuma PDF paliek lokāli un netiek publicēts repozitorijā.

Komandas apraksts: [Microsoft FOR dokumentācija](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/for).
